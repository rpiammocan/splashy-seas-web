# Splashy Seas Web

**Version 1.0**

Splashy Seas is a kid-friendly browser game where players swim through colorful ocean scenes, dodge obstacles, and reach the treasure at the end.

## Play

This repository is designed for GitHub Pages. Once Pages is enabled for the `main` branch, the game runs directly from `index.html`.

## Gameplay

- Choose from Mermaid, Scuba Guy, Friendly Torpedo, or Mermacorn.
- Choose one of six ocean scenes.
- Choose Easy, Medium, or Hard difficulty.
- Dodge the two obstacles assigned to the selected scene.
- Earn 1 point for each obstacle passed.
- You have 3 lives.
- Each round lasts 45 seconds.
- Swim into the treasure at the end to finish.
- Press `Esc` during gameplay to return to the home screen.

## Controls

- `Up Arrow` / `W` — swim up
- `Down Arrow` / `S` — swim down
- `Esc` — return home

## Release

Splashy Seas Web V1.0 is based on the completed Splashy Seas V30 development build.
